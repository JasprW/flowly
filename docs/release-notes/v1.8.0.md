# Flowly 1.8.0

Covers everything merged to `main` since v1.7.2 (#71–#94). The headline is guardrails: project memory, the workpad, auto review and Insights now work as one loop. The in-app *What's new* window shows the highlights marked ★.

## New

- ★ **Auto review.** When an agent delivers a card to In review, Flowly runs the project's check commands, then a temporary reviewer session judges the change against the card, its sessions and the project's guidelines. A failure sends the card back to its work stage with what fell short; past the rework limit it goes to Blocked. A pass never moves a card to Done. On for new projects; turn it on for an existing one in its settings or from What's new. (#75, #93, #94)
- ★ **Guardrails learn from what you send back.** Sending a card back notes what was wrong; the second card with the same problem turns it into a project guideline, checked on every later delivery it applies to. Guidelines that keep misfiring or never catch anything retire by themselves. (#75)
- ★ **Memory without confirming.** What agents remember with `flowly_remember` takes effect at once in new sessions' first instructions, and unused entries retire by themselves. Filter, sort, pin, edit, archive, or copy one as an `AGENTS.md` rule. (#75)
- ★ **Search** past cards, summaries, progress notes, workpads, ideas and deliverables (`S`). A hit opens the card at its section and highlights the words. Agents search the same history with `flowly_search`. (#71–#73)
- ★ **Shortcut** stories and epics as card inputs, next to Jira, Confluence, GitHub, GitLab and Azure DevOps. (#78)
- **Phone board:** swipe between lanes; the header keeps only the project picker, Attention, search and filters; New task is a floating button. Android Back steps back through Flowly before Paseo closes it. (#79–#81)
- Session preview shows inline UI fences as a collapsed notice. (#82)
- Automation names for cards and lanes. (#84)
- Usage stats read dsh-web provider logs. (#89)

## Improved

- The Flowly MCP is added at each session launch instead of being saved in the agent config. (#88)
- The card sidebar remembers its width; the opened card scrolls into view in its lane.
- Session links: `<angle>` and bare URLs open; local file links copy the absolute path.

## Fixed

- Insights skips runs whose workspace directory Paseo removed. (#91)
- Pending questions scroll with the transcript instead of sticking above the composer.
- The Ideas popover is one layer with the host's.
- Text boxes block board shortcuts while focused.

## Upgrade

Requires Paseo 0.15.0 or later (plugin hooks moved to Paseo's `addHook`, #92). Existing data and settings are preserved. Auto review stays off for existing projects until you turn it on; each review uses tokens.
